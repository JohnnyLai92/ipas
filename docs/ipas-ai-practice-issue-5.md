## 逐題錯誤分析

### 第 3 題（多選）— 過擬合改善方法

- **你的作答**：A、B
- **正確答案**：A、B、D、E
- **錯誤原因**：屬「漏選」。你選出的 A（增資料／Data Augmentation）、B（正則化／Dropout）皆正確，但漏了 D（Early Stopping）與 E（降低模型複雜度）。
- **正確觀念**：過擬合（Training 高、Validation 低）代表模型過度記憶訓練資料。改善方向是「增加資料多樣性」或「降低模型有效複雜度」。C（大幅增加層數與參數量）方向相反，會**加劇**過擬合，屬誘答選項。
- **相關考點（L23304）**：Overfitting / Underfitting 判讀；正則化（L1／L2）、Dropout、Early Stopping、資料擴增、降低模型複雜度、交叉驗證等對策清單。

### 第 5 題（單選·計算）— Precision 計算

- **你的作答**：B（0.57）
- **正確答案**：D（0.80）
- **錯誤原因**：公式套錯。混淆矩陣為 TP=40、FP=10、FN=20、TN=30。
  - 正解：Precision = TP ÷ (TP + FP) = 40 ÷ (40 + 10) = **0.80**
  - 誤區：0.57 是把 FN 混進分母（如 40÷(40+10+20) 之類），把 Precision 與 Recall 的分母搞混。
- **正確觀念**：
  - **Precision = TP / (TP + FP)**：預測為正的樣本中，真正為正的比例。
  - **Recall = TP / (TP + FN)**：實際為正的樣本中，被正確抓回的比例。
  - Precision 分母只看「預測為正」，與 FN 無關。
- **相關考點（L23303）**：Confusion Matrix、Precision／Recall／F1／Accuracy 四大指標公式與適用情境。

### 第 7 題（情境／單選）— Transfer Learning

- **你的作答**：B（Linear Regression）
- **正確答案**：C（Transfer Learning／Fine-tuning）
- **錯誤原因**：選型錯誤。情境為「少量標記影像（2,000 張）＋ GPU 資源有限 ＋ 需維持準確率」，這是遷移學習的標準教科書情境。B（Linear Regression）為回歸法，不適用影像分類。
- **正確觀念**：資料量少、算力有限時，使用預訓練模型（pretrained model）進行 Transfer Learning／Fine-tuning，可借用大型資料集學到的特徵，用少量資料即獲得良好準確率。
- **相關考點（L23203）**：深度學習應用、預訓練模型、遷移學習的適用時機。

### 第 8 題（單選·程式判讀）— PyTorch Tensor Shape

- **你的作答**：B（torch.Size([4, 2])）
- **正確答案**：C（torch.Size([10, 2])）
- **錯誤原因**：誤把 `nn.Linear` 的參數當成輸出形狀。`nn.Linear(4, 2)` 表示「輸入特徵維度 4 → 輸出特徵維度 2」，只作用於**最後一維**。
  - 輸入 `x` 形狀為 (10, 4)，batch 維度 10 不變 → 輸出為 **(10, 2)**。
- **正確觀念**：`nn.Linear(in_features, out_features)` 僅改變張量的最後一維，batch（第一維）維度保持不變。這類題建議動手 `print(shape)` 驗證，不要靠猜。
- **相關考點（L23203 / 線性代數）**：矩陣乘法與張量維度（Tensor Shape）判讀、全連接層運作原理。

### 第 9 題（多選）— Activation Function

- **你的作答**：B、C
- **正確答案**：A、B、C
- **錯誤原因**：屬「漏選」。你選的 B（Softmax 多分類機率）、C（ReLU 負值歸零、緩解梯度消失）皆正確，但漏了 A（Sigmoid 將輸出壓縮到 0～1）。
- **正確觀念**：
  - A ✅ Sigmoid：值域 (0, 1)。
  - B ✅ Softmax：多分類輸出層，各類別輸出可視為機率（總和為 1）。
  - C ✅ ReLU：負值輸出 0，緩解梯度消失並加速訓練。
  - D ❌ 激活函數的核心功能是提供**非線性表達能力**，而非「只加快訓練速度」。
- **相關考點（L23203）**：常見激活函數（Sigmoid／Softmax／ReLU／Tanh）的值域與用途、非線性的重要性。

## 錯題共同弱點（題型分析）

1. **多選題「寧缺勿濫」導致漏選（第 3、9 題）**
   兩題皆為漏選而非錯選——選出的選項全對，代表觀念正確，但沒有把所有正確選項挑齊。多選題須逐一判斷每個選項真偽，不能選到「明顯對的」就停手。

2. **計算與定義精確度不足（第 5 題）**
   Precision／Recall 公式混淆是歷年最大陷阱。務必區分分母：Precision 看 (TP+FP)，Recall 看 (TP+FN)。

3. **應用場景 → 方法對應不熟（第 7、8 題）**
   第 7 題為情境選型（少資料＋低算力 → Transfer Learning）；第 8 題為程式判讀（`nn.Linear` 只改最後一維）。需建立「條件 → 首選策略」直覺，並實作驗證 tensor 維度。

> **補充觀察**：本次錯題（3、5、7、8、9）多落在內文「作答格式範本」的預設 B 值附近，需留意是否受範本 anchoring 影響，務必逐題實際判斷。
