## 逐題錯誤分析

### 第 7 題〔多選 · L23304 過擬合改善方法〕

**題目重點**：下列哪些做法有助於改善過擬合（Overfitting）？

- (A) 增加訓練資料量或使用 Data Augmentation
- (B) 加入 L1／L2 Regularization 或 Dropout
- (C) 大幅增加網路層數與參數量
- (D) 採用 Early Stopping（提早停止訓練）
- (E) 適度降低模型複雜度

**你的作答**：ABCE　**正確答案**：ABDE

#### 錯誤原因

1. **誤選 (C)**：把「增加模型複雜度」當成改善過擬合的方法。事實上，過擬合的本質就是模型「太複雜、記住了訓練集」，大幅增加層數與參數量只會**加重**過擬合，屬於典型的反向干擾選項。
2. **漏選 (D)**：Early Stopping（提早停止訓練）是防止過擬合的標準手段之一，屬於「正則化家族」，卻被漏掉。
3. **多選題計分規則**：漏選 (D)、多選 (C)，只要不完全正確即不予計分，故本題失分。

#### 正確觀念

過擬合 = 模型過度複雜、對訓練集記憶過強、泛化能力差。正確的改善方向為「**讓模型變簡單、更泛化**」：

- (A) 增加訓練資料量 / Data Augmentation → 讓模型看到更多樣本，難以死記 ✅
- (B) L1／L2 Regularization、Dropout → 抑制參數過度擬合 ✅
- (D) Early Stopping → 在驗證誤差開始上升前停止，避免過度訓練 ✅
- (E) 適度降低模型複雜度 → 直接減少過擬合的根源 ✅
- (C) 增加層數與參數量 → **惡化**過擬合，應排除 ❌

#### 相關機器學習考點

- **過擬合 vs 欠擬合（L23302 / L23304）**：兩者的處置方向恰好相反，需連結記憶。
  - 過擬合 → 減複雜度、加正則化（L1/L2/Dropout）、增資料、Data Augmentation、Early Stopping
  - 欠擬合 → 增複雜度、增特徵、減正則化、延長訓練
- **正則化家族**：L1/L2、Dropout、Early Stopping、Data Augmentation 都可視為廣義的正則化 / 抗過擬合手段。
- **與第 3 題互為正反面**：第 3 題（訓練 98% / 驗證 70% → 過擬合）與第 7 題同屬 L233 模型泛化主題，建議綁在一起複習，強化正反雙向判斷。
