## 每題錯誤分析

### 第 1 題（L23201 機器學習原理）— 半監督式學習

- **你的作答**：(A) 純監督式學習，只用 2,000 張已標記影像
- **正確答案**：(B) 半監督式學習（Semi-Supervised Learning）
- **錯誤原因**：未抓住題幹關鍵字「**同時**運用少量已標記與大量未標記資料」，把它誤判為純監督。只用 2,000 張是純監督，會浪費 9.8 萬張未標記資料。
- **正確觀念**：半監督式學習的定義正是「少量標記 + 大量未標記」同時使用，藉未標記資料的分布資訊提升泛化。
- **機器學習考點**：學習範式辨識
  - 監督式：全部資料有標籤。
  - 非監督式：完全無標籤（如分群）。
  - 半監督式：少量標記 + 大量未標記。
  - 強化學習：與環境互動、以獎勵訊號學習策略。

### 第 3 題（L23203 深度學習框架．程式判讀）— 神經網路輸出維度

- **你的作答**：(B) torch.Size([32, 10])
- **正確答案**：(C) torch.Size([32, 3])
- **錯誤原因**：把中間隱藏層維度（10）當成輸出維度。
- **正確觀念**：`nn.Sequential` 的最終輸出維度由**最後一層** `nn.Linear(10, 3)` 的 `out_features=3` 決定；batch 維（32）保持不變，故輸出為 `[32, 3]`。中間的 10 只是隱藏層寬度。
- **機器學習考點**：看到 `nn.Sequential`，輸出形狀 = `(batch, 最後一個 Linear 的 out_features)`；ReLU 等激活函數不改變張量形狀。

### 第 4 題（L23202 特徵縮放）— 哪些演算法對縮放敏感

- **你的作答**：A, C, D
- **正確答案**：A, C, E
- **錯誤原因**：多勾 (D) 隨機森林、漏勾 (E) 以梯度下降訓練的邏輯回歸。
- **正確觀念**：
  - 對縮放**敏感**：KNN（距離）、RBF-SVM（距離／核）、以梯度下降訓練的邏輯回歸（梯度）。
  - 對縮放**不敏感**：決策樹、隨機森林（基於特徵分裂點，與尺度無關）。
- **機器學習考點**：記憶口訣——「**距離／梯度模型敏感**（KNN、SVM、邏輯回歸、神經網路、K-Means、PCA）；**樹模型不敏感**（決策樹、隨機森林、GBDT）」。

### 第 6 題（L23301 特徵工程）— 無序類別編碼

- **你的作答**：(B) Label Encoding（A/B/O/AB → 0/1/2/3）
- **正確答案**：(A) One-Hot Encoding
- **錯誤原因**：血型彼此無大小順序，Label Encoding 會讓模型誤讀成 0 < 1 < 2 < 3 的數值大小關係，對距離／梯度模型造成錯誤假設。
- **正確觀念**：**無序（名目）類別**應用 One-Hot Encoding，避免捏造順序；Label Encoding 只適合**有序類別**（如低／中／高）或對縮放不敏感的樹模型。
- **機器學習考點**：名目 vs 順序類別的編碼選擇。

### 第 7 題（L23303 評估指標）— Precision vs Recall

- **你的作答**：(A) Recall（召回率）
- **正確答案**：(B) Precision（精確率）
- **錯誤原因**：把「被判為瑕疵者應盡量真的是瑕疵」（降低偽陽性 FP）誤配成 Recall。
- **正確觀念**：題幹在意「不要浪費拆解成本在良品上」＝被模型判為正（瑕疵）之中真的為正的比例＝**Precision = TP / (TP + FP)**。Recall = TP / (TP + FN) 關注的是「該抓的別漏掉」。
- **機器學習考點**：判斷口訣
  - 在意「挑出來的別挑錯、省成本」→ **Precision**。
  - 在意「該抓的別漏掉（別放過瑕疵／病人）」→ **Recall**。

### 第 8 題（L23304 模型調整）— 改善欠擬合的方向

- **你的作答**：B, C, D, E
- **正確答案**：A, B, D, E
- **錯誤原因**：多勾 (C)「大幅加強 L2 正則化」、漏勾 (A)「增加模型複雜度」，把調整方向搞反。
- **正確觀念**：欠擬合＝模型能力不足，要**增加能力**：加複雜度(A)、加特徵(B)、延長訓練(D)、**放寬**正則化(E)。加強正則化(C) 會抑制模型能力、使欠擬合更嚴重，那是對付**過擬合**的手段。
- **機器學習考點**：欠擬合 ↔ 過擬合的對稱調整方向。
  - 欠擬合：加料、放寬正則化、加訓練。
  - 過擬合：加正則化、減複雜度、增資料、Early Stopping。

### 第 10 題（L23101 貝氏定理）— base rate 陷阱

- **你的作答**：(A) 約 95%
- **正確答案**：(B) 約 8.8%
- **錯誤原因**：直接把敏感度 95% 當成患病機率，落入 base rate（先驗盛行率）直覺陷阱。
- **正確觀念**：套完整貝氏公式：

  ```
  P(病|陽) = P(陽|病)·P(病) / [P(陽|病)·P(病) + P(陽|健)·P(健)]
           = (0.95 × 0.01) / (0.95 × 0.01 + 0.10 × 0.99)
           = 0.0095 / (0.0095 + 0.099)
           = 0.0095 / 0.1085 ≈ 8.8%
  ```

  低盛行率下，健康者眾多，即使偽陽性率僅 10%，偽陽性的絕對數量仍遠超真陽性，故陽性者實際患病機率偏低。
- **機器學習考點**：貝氏定理與 base rate；養成「先算分母（全部陽性）」的習慣。

## 弱點歸納（題型分析）

答錯集中在本輪題頭已預告的「易失分觀念」，可歸為四類：

1. **學習範式辨識（Q1）**：未抓「同時用已標記＋未標記」關鍵字，半監督誤判為純監督。
2. **評估指標方向（Q7）**：Precision 與 Recall 混淆。
3. **過擬合 ↔ 欠擬合的調整方向（Q4、Q8）**：正則化與複雜度的加減方向搞反；且對「哪些演算法對特徵縮放敏感」記憶不牢（樹模型不敏感）。
4. **基礎數理與框架細節（Q3、Q6、Q10）**：
   - 神經網路輸出維度只看最後一層 + batch。
   - 無序類別必用 One-Hot。
   - 貝氏定理的 base rate 陷阱。

## 後續複習建議

- **L23201 學習範式**：把「監督／半監督／非監督／強化」做一張一句話關鍵字對照表（半監督＝少量標記＋大量未標記）。
- **L23303 評估指標**：親手畫 2×2 混淆矩陣，推導 Precision = TP/(TP+FP)、Recall = TP/(TP+FN)，各配一個生活情境（省成本→Precision；別漏抓→Recall）。
- **L23304 擬合方向**：製作「欠擬合 vs 過擬合」對照卡（症狀＋對策），特別標註「正則化↑＝抑制過擬合、放寬正則化＝改善欠擬合」。
- **特徵縮放**：熟記「距離／梯度模型敏感（KNN、SVM、邏輯回歸、神經網路、K-Means、PCA）；樹模型不敏感（決策樹、隨機森林、GBDT）」。
- **L23301 編碼**：無序類別 → One-Hot；有序類別 → Label／Ordinal。
- **L23101 貝氏**：練 3～5 題不同盛行率的篩檢題，養成「先算分母」的習慣，破除 base rate 直覺陷阱。
- **L23203 PyTorch**：看到 `nn.Sequential`，輸出維度＝最後一個 `Linear` 的 `out_features`，batch 維不變；激活函數不改變形狀。

**重點方向**：把「調整方向性（欠擬合 vs 過擬合）」與「base rate（貝氏）」兩個直覺矯正過來，分數可明顯回升。
