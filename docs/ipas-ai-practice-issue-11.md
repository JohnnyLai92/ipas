## 二、逐題錯誤分析

### 第 1 題〔單選〕L23101 機率／統計（貝氏定理）❌

- **你的作答**：(C) 0.05
- **正確答案**：(B) 0.32
- **錯誤原因**：把「先驗機率」誤當成「後驗機率」。0.05 只是「尚未看檢測結果前」的瑕疵率（base rate），但題目問的是「已被儀器判定為瑕疵之後」，實際為瑕疵的機率，必須用貝氏定理更新。
- **正確觀念（貝氏定理）**：

  P(瑕疵∣檢測瑕疵) = P(瑕疵)·P(檢測瑕疵∣瑕疵) / P(檢測瑕疵)

  分母 P(檢測瑕疵) = P(瑕疵)·P(檢測∣瑕疵) + P(良品)·P(檢測∣良品)
  = 0.05×0.9 + 0.95×0.1 = 0.045 + 0.095 = 0.14

  ∴ 後驗機率 = 0.045 / 0.14 ≈ **0.321**

- **相關考點**：先驗（prior）→ 概似（likelihood）→ 後驗（posterior）的更新流程；**低盛行率（rare event）下，即使檢出率高，後驗機率仍可能偏低**（大量良品的誤報會稀釋掉真陽性）。

### 第 6 題〔單選〕L23202 常見機器學習演算法（特徵縮放）❌

- **你的作答**：(B) Random Forest（隨機森林）
- **正確答案**：(C) KNN（K-最近鄰）
- **錯誤原因**：選了「不需要縮放」的樹型演算法。隨機森林／決策樹基於**分裂閾值**逐特徵切分，對特徵尺度不敏感；你選的正是「不需縮放」的代表。
- **正確觀念**：KNN 以**距離**（如歐氏距離）計算相似度，若各特徵尺度差異大，大尺度特徵會主宰距離度量，因此**最依賴特徵縮放**。
- **相關考點（縮放敏感度對照）**：
  - **需要縮放**：距離型（KNN、K-Means、SVM）、梯度型（線性／羅吉斯回歸、神經網路）、PCA。
  - **不需要縮放**：樹型（決策樹、隨機森林、GBDT）、Naive Bayes（基於機率）。

### 第 7 題〔多選（4 項）〕L23203 深度學習原理（激活函數與架構）❌

- **你的作答**：(A)(C)(D)(E)
- **正確答案**：(A)(B)(C)(E)
- **錯誤原因**：**漏勾正確的 (B)、多勾錯誤的 (D)**，雙重失分。
  - (D) 錯誤：**Sigmoid 輸出範圍是 [0, 1]**，而 [-1, 1] 是 **tanh**。
  - (B) 正確卻漏勾：Softmax 常用於多類別分類輸出層，將輸出轉為機率分布。
- **正確觀念（激活函數值域速記）**：
  - Sigmoid → [0, 1]
  - tanh → [-1, 1]
  - ReLU → [0, ∞)，正區間梯度為常數，有助緩解梯度消失
  - Softmax → 多類別機率分布（總和為 1）
- **相關考點**：CNN 適合空間結構影像；RNN／LSTM 適合時間／順序序列資料。

### 第 9 題〔多選（3 項）〕L23303 評估指標／L23402 公平性 ❌

- **你的作答**：(A)(C)(D)
- **正確答案**：(B)(C)(D)
- **錯誤原因**：誤選了陷阱選項 (A)，並漏勾關鍵的 (B)。
  - (A) 陷阱：詐欺僅占 0.5%，**整體 Accuracy 會被多數類（正常交易）灌水**，無法反映對少數類的偵測力。
  - (E) 陷阱：全判「正常」也能有 99% 以上 Accuracy，卻完全漏掉詐欺，毫無用處。
  - (B) 關鍵漏勾：業務目標是「盡量不漏掉詐欺」，直接對應**重視 Recall（召回率）、降低 False Negative（把真詐欺漏判為正常）**。
- **正確觀念（極度不平衡資料評估）**：不可單看 Accuracy；應綜合 Precision、Recall、F1-score 與混淆矩陣，並依業務目標（反詐欺、醫療篩檢）以 **Recall 優先**；同時檢查對不同客群（年齡、地區）的攔截率是否有明顯偏差（公平性）。

## 三、共通問題與弱點歸納

1. **先驗 vs 後驗、base rate 的統計直覺（Q1、Q9）**
   - 共同盲點：混淆先驗與後驗機率、忽略類別極度不平衡時的指標選擇。「Accuracy 在不平衡下失真」與「Recall 對應不可漏判」其實是同一個 base rate 觀念的一體兩面。

2. **演算法對特徵縮放的敏感度（Q6）**
   - 需建立「吃距離／梯度 vs 吃分裂規則」的分類記憶：距離型／梯度型需縮放，樹型不需縮放。

3. **激活函數輸出範圍細節（Q7）**
   - Sigmoid [0,1] 與 tanh [-1,1] 值域混淆。

4. **多選題作答行為（Q7、Q9）**
   - 兩題皆出現「漏一個正確 + 補一個錯誤」。應**逐個選項獨立判對錯後再統計勾選數**，切勿為湊題目指定項數而硬選。

## 四、後續複習建議

1. **貝氏定理**：熟練分母展開 P(檢測瑕疵)=P(瑕疵)P(檢測∣瑕疵)+P(良品)P(檢測∣良品)，並理解為何低盛行率下高檢出率仍可能導致低後驗機率。
2. **不平衡分類評估**：背熟混淆矩陣與 Precision／Recall／F1 定義，認得 Accuracy 陷阱，理解反詐欺／醫療篩檢為何 Recall 優先。
3. **特徵縮放對照表**：整理「需要／不需要縮放」演算法清單（距離型、梯度型 vs 樹型）。
4. **激活函數速記卡**：Sigmoid [0,1]、tanh [-1,1]、ReLU [0,∞)、Softmax（多類別機率分布），連同梯度特性一起記。
5. **多選題作答策略**：每個選項單獨驗證對錯後再統計，避免「漏正確 + 補錯誤」的雙重失分。
