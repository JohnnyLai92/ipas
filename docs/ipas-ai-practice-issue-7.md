## 逐題錯誤分析

### 第 5 題 — Precision 計算（L23303）

**題目**：混淆矩陣 TP = 40、FP = 10、FN = 20、TN = 30，求 Precision。

- **你的答案**：B（0.67）
- **正確答案**：D（0.80）

**錯誤原因**：
把 Precision 與 Recall 的公式記混了。0.67 = 40/(40+20) 其實是 **Recall** 的算式，誤用了「實際為正的總數（TP+FN）」當分母。

**正確觀念**：
- **Precision（精確率）= TP / (TP + FP) = 40 / (40 + 10) = 40 / 50 = 0.80**
- 分母是「模型判為正的總數（TP + FP）」，意義是「模型說是正的裡面，有多少真的是」。

**相關機器學習考點**：
- 混淆矩陣四大指標（L23303）：Accuracy、Precision、Recall、F1-Score。
- 關鍵區分：
  - **Precision = TP / (TP + FP)** — 分母是「模型判為正」的總數。
  - **Recall = TP / (TP + FN)** — 分母是「實際為正」的總數。

### 第 6 題 — 深度學習應用策略（L23203）

**題目**：僅有 2,000 張已標記瑕疵圖片、GPU 資源有限，欲快速建立可用的影像分類模型，最適策略為何？

- **你的答案**：C（改用 K-Means 分群取代分類）
- **正確答案**：B（Transfer Learning + Fine-tuning）

**錯誤原因**：
誤把「非監督式分群（K-Means）」當成分類任務的替代方案。K-Means 無法利用既有的標記資料，也不是分類演算法，無法產出「瑕疵 / 正常」的分類判斷。

**正確觀念**：
- **小資料 + 少算力 → Transfer Learning（遷移學習）+ Fine-tuning** 幾乎是標準解。
- 使用 ImageNet 等預訓練模型，只需少量資料與算力即可微調出可用成效。
- (A) 從零訓練超大 CNN：小資料上必然過擬合且耗資源。
- (C) K-Means 是非監督分群，無法取代「有標記」的監督分類任務。
- (D) Linear Regression 是回歸模型，不適合影像分類。

**相關機器學習考點**：
- 深度學習應用策略（L23203）：建立「情境關鍵字 → 策略」直覺。
  - 資料少 / 算力少 → 遷移學習。
  - 監督分類任務 → 不可用分群演算法取代。

### 第 7 題 — 過擬合改善方法（L23304，多選）

**題目**：哪些做法有助於改善過擬合？（多選）

- **你的答案**：A, B, D
- **正確答案**：A, B, D, E（漏選 E）

**錯誤原因**：
過擬合改善方法清單沒記全，漏了 **(E) 適度降低模型複雜度**。過擬合的本質就是「模型太複雜、死背訓練集」，因此所有「讓模型變簡單」的手段都成立。

**正確觀念**：
- 改善過擬合的完整手段：
  - (A) 增加訓練資料 / Data Augmentation ✓
  - (B) Regularization（L1／L2）／ Dropout ✓
  - (D) Early Stopping ✓
  - (E) 適度降低模型複雜度 ✓
- (C) 大幅增加網路層數與參數量：反而**加劇**過擬合，為正反成對的干擾選項。

**相關機器學習考點**：
- 過擬合 vs 欠擬合對策（L23302／L23304）：
  - **過擬合對策**：加資料、正則化、Dropout、Early Stopping、降低複雜度。
  - **欠擬合對策**：增加複雜度、加特徵、減少正則化。
  - 兩邊剛好相反，成對記憶最牢。
