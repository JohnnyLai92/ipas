## 逐題錯誤分析

### 第 3 題〔單選 · 程式判讀〕L23203 深度學習原理與框架

**題目情境**：
```python
import torch
import torch.nn as nn

model = nn.Linear(8, 3)
x = torch.randn(16, 8)
y = model(x)
print(y.shape)
```

- **你的作答**：D（torch.Size([8, 3])）
- **正確答案**：B（torch.Size([16, 3])）

**錯誤原因**：
把 `nn.Linear(8, 3)` 的**權重矩陣形狀 [8, 3]** 誤當成輸出張量形狀。忽略了輸入 `x` 的 batch 維度會被保留。

**正確觀念（`nn.Linear` 的形狀轉換）**：
- `nn.Linear(in_features, out_features)` 代表「輸入 8 維 → 輸出 3 維」的全連接層。
- 輸入 `x` 形狀為 `(16, 8)`，其中 **batch=16 不變**，只有**特徵維由 8 映射到 3**。
- 故輸出形狀為 `(16, 3)`，即規則 `(N, in) → (N, out)`。

**相關機器學習考點**：
神經網路前向傳播的維度對齊、batch 維與特徵維的區分。與 `nn.Conv2d`、矩陣乘法 shape mismatch 除錯同屬基本功。

### 第 4 題〔單選〕L23301 數據準備與特徵工程

**題目情境**：「產線機台代號」欄位值為 M1、M2、M3、M4，彼此**無大小或順序關係**，後續要餵入對數值大小敏感的模型（KNN、邏輯回歸），最恰當的編碼方式？

- **你的作答**：A（Label Encoding，轉為 0/1/2/3）
- **正確答案**：D（One-Hot Encoding）

**錯誤原因**：
對**無序名目類別**使用 Label Encoding，會把 M1~M4 轉為 0/1/2/3，讓對數值大小敏感的模型（KNN、邏輯回歸）誤以為 `M4 > M1`，引入**虛假的順序與距離關係**。

**正確觀念（編碼決策）**：
- **無序（名目型）類別** → **One-Hot Encoding**，各類別轉為獨立 0/1 欄位，彼此等距，避免虛假順序。
- **有序（順序型）類別**（如小／中／大） → Label／Ordinal Encoding 才恰當。
- 判斷關鍵二問：①「類別是否有順序關係」②「模型是否對數值大小敏感」。維度爆炸時可再考慮目標編碼等進階法。

**相關機器學習考點**：
特徵工程中類別變數的處理、模型對輸入尺度／距離的假設（KNN 用距離、邏輯回歸用線性權重）。

### 第 8 題〔多選（可勾選 3 項）〕L23203 深度學習原理與框架

**題目**：下列關於深度學習模型與概念的敘述，哪些正確？（勾選 3 項）

- **你的作答**：A、B、D
- **正確答案**：A、B、C

**錯誤原因**：
- **(C) 漏勾**：Transfer Learning 可在小型資料集上運用預訓練模型、降低訓練成本，敘述**正確**，卻未勾選。
- **(D) 多勾**：ReLU 為 `max(0, x)`，只把負值截為 0、正值原樣輸出，**並非壓縮到 0~1**。把值域壓到 0~1 的是 **Sigmoid**，敘述錯誤卻誤勾。

**正確觀念（激勵函數對照 & 遷移學習）**：

| 激勵函數 | 公式／行為 | 值域 |
|---|---|---|
| Sigmoid | 1/(1+e^-x) | (0, 1) |
| Tanh | 雙曲正切 | (−1, 1) |
| ReLU | max(0, x) | [0, ∞) |
| Softmax | 指數正規化 | 機率分布，總和=1 |

- (A) CNN 透過卷積擷取空間特徵，常用於影像辨識 ✅
- (B) LSTM 以閘門機制緩解梯度消失，較一般 RNN 更能處理長期依賴 ✅
- (E) 增大 Batch Size **不保證**提升準確率，正確排除。

**相關機器學習考點**：
激勵函數值域與用途（Sigmoid vs ReLU 為常見陷阱）、Transfer Learning、CNN/LSTM 架構特性、Batch Size 的影響。

### 第 10 題〔情境分析 · 單選〕L23202 常見機器學習演算法

**題目情境**：僅約 2,000 張已標記瑕疵影像、GPU 資源有限，希望**快速**建立成效不錯的影像**分類**模型，最適合的策略？

- **你的作答**：B（改用 K-Means 非監督分群取代分類）
- **正確答案**：D（Transfer Learning，微調預訓練 CNN）

**錯誤原因**：
選了 K-Means。但 K-Means 是**非監督分群**，無法取代**有標記的瑕疵分類任務**，也未善用既有標記資料，效果通常不佳。混淆了「分類」與「分群」的任務型態。

**正確觀念（演算法選型）**：
- 小資料集（2,000 張）+ 資源有限 + 需快速上線 + **分類任務** → **Transfer Learning + Fine-tune 預訓練 CNN**。
- 預訓練模型已學到通用視覺特徵，只需微調少量層即可，訓練成本低、收斂快、成效佳。
- (A) 從零訓練超大型網路 → 資料不足易過擬合、耗資源，排除。
- (B) K-Means 分群 → 任務型態錯誤（分群 ≠ 分類），排除。
- (C) 全改人工全檢 → 放棄自動化，排除。

**相關機器學習考點**：
任務型態辨識（分類 vs 分群）、Transfer Learning 的適用情境、資料量與模型複雜度的權衡。

## 後續複習建議

四題失分集中在三大弱點，建議依序補強：

1. **深度學習框架與基礎觀念（L23203，第 3、8 題）— 最需鞏固**
   - `nn.Linear(in, out)` 的形狀規則：**batch 維不變，只有特徵維被映射**，牢記 `(N, in) → (N, out)`。
   - 動手實跑 `nn.Linear`、`nn.Conv2d`，觀察 `.shape` 變化，建立維度直覺。
   - 背熟**激勵函數對照表**：Sigmoid(0~1)、Tanh(−1~1)、ReLU(max(0,x))、Softmax(機率分布)，尤其別把 ReLU 與 Sigmoid 搞混。

2. **特徵工程的編碼選擇（L23301，第 4 題）**
   - 編碼決策流程：先問「類別有無順序」→ **無序用 One-Hot、有序用 Ordinal**；再看模型是否對數值大小敏感。
   - 記住反例：對無序類別用 Label Encoding 會引入虛假順序，傷害 KNN／邏輯回歸等模型。

3. **演算法選型的情境判斷（L23202，第 10 題）**
   - 先辨識**任務型態**（分類需標記、分群不需），再對應資料條件。
   - 口訣：**小資料／少資源／要快 → 遷移學習**；要可解釋 → 決策樹；要抓全（不漏） → Recall；要準（不誤報） → Precision。

4. **維持優勢**
   - 半監督式學習（第 1）、決策樹可解釋性（第 2）、Recall 取捨（第 5）、學習率發散（第 6）、過擬合對策（第 7）、醫療合規（第 9）全數正確，觀念穩固，維持即可。
